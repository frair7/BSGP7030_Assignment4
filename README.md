# BSGP7030_Assignment4
Assignment 4 from BSGP 7030 – Python Statistics and Plotting

## Overview

The purpose of this assignment was to work through the SciPy Statistics tutorial and gain experience using Python to perform common statistical analyses and create visualizations. Rather than simply running the code, the goal was to understand what each section was doing, why it was being used, and how to interpret the results.

This assignment also reinforced good project organization by creating a reproducible Conda environment, documenting package requirements, and maintaining everything under version control with GitHub.

---

## Files Included

* `notebooks/stats_python.ipynb` – Manual walkthrough of the SciPy Statistics tutorial
* `notebooks/stats_python.html` – Executed HTML version of the notebook
* `data/` – Data files used throughout the notebook
* `environment.yml` – Conda environment used for the project
* `requirements.txt` – Python package requirements
* `README.md` – Project documentation

---

## Topics Covered

Some of the statistical concepts covered in this assignment include:

* Loading and exploring datasets with pandas
* Summary statistics
* Data visualization with Matplotlib
* Comparing groups using t-tests
* Correlation analysis
* Linear regression
* ANOVA
* Working with multiple datasets
* Interpreting statistical output

## Running the Notebook

Create the Conda environment:

```bash
conda env create -f environment.yml
```

Activate the environment:

```bash
conda activate 7030_class_4
```

Launch Jupyter:

```bash
jupyter notebook
```

Open:

```
notebooks/stats_python.ipynb
```
